# centroid-erasure
Code and artifacts for "The Cost of Language: Centroid Erasure Exposes and Exploits Modal Competition in Multimodal Language Models" (COLM 2026). Centroid replacement, a training-free probe for text-vs-visual dependence in multimodal LMs, and text centroid contrastive decoding (TCCD) are included. Pre-print: https://arxiv.org/abs/2604.14363
